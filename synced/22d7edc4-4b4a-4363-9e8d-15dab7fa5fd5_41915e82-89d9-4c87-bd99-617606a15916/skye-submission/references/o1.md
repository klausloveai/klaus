# O-1 split plan

```
forms                    →  each form stays its own PDF, untouched
consultation / union      →  one PDF on its own
identity documents        →  one PDF (passport, visa, spouse visa, I-94)
petition letter + index
  + all remaining exhibits →  split into files of at most 11,920,000 bytes
```

**Forms** are uploaded individually against their own USCIS slots. Leave them alone — do not
merge or re-compress them. The O-1 set:

| Form | What it is | Notes |
|---|---|---|
| G-1650 | filing fee | one form per fee. $530 + $300 for a small petitioner, $1,055 + $600 above 25 US employees, plus $2,965 if premium |
| G-28 | attorney appearance | signatures in Part 4 (client) and Part 5 (attorney) |
| I-907 | premium processing | omit if not filing premium |
| G-1145 | e-notification | **only** when not filing premium; goes first in the package |
| I-129 | the petition | print **P1-8 and P28-30** only — the main form plus the O and P Classifications Supplement |

The I-129 scan that comes back from the scanner usually holds all 38 pages, including the
E-1/E-2, Trade Agreement, H, Q-1 and R-1 supplements that do not apply to an O-1. Trim to the
pages the checklist names.

**Consultation / union letter** files separately, so it gets its own PDF containing its
section cover page, its item cover page, and the letter. Build it as a whole block: an
exhibit's section cover and its item cover are two separate index entries, and splitting
between them leaves a one-page file containing nothing but a heading.

Because it ships separately, decide with the attorney whether it *also* stays inside the main
exhibit run. Keeping it in both places is the safe default — the index lists it either way —
but confirm rather than assume, and if it is pulled out, page numbering for the rest of the
exhibits closes up behind it.

**Identity documents** merge into one PDF. Passport bio page, visa page, I-94, and any
dependent/spouse visa pages.

**Petition letter + index + exhibits.** The letter and index lead the first file; say so in
that file's label. Aim for five files unless the material genuinely will not fit — five is
what the firm has been filing, and more files means more upload slots to keep straight.

Exhibit page numbering runs continuously across the split set so a page cited in one file can
be found without knowing which file it landed in.
