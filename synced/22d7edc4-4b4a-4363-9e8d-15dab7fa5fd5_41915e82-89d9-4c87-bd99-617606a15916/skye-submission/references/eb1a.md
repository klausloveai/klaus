# EB-1A split plan

```
forms                     →  each form stays its own PDF, untouched
identity documents         →  one PDF
future plan                →  one PDF
US-benefit evidence        →  one PDF
petition letter
  + all remaining exhibits →  split into files of at most 11,920,000 bytes
```

EB-1A differs from O-1 in that two argument-specific bundles come out as their own documents.

**Future plan** — the beneficiary's plan of continued work in the field. In the firm's EB-1A
template this lives under `5. LOI and Future Plan`, alongside the letters of intent. It is
read as a unit, so it files as a unit.

**US-benefit evidence** — the material supporting substantial prospective benefit to the
United States. Same reasoning: an adjudicator reads it as one argument.

Both are argued in the petition letter and listed in the index like any other exhibit, so
they keep their cover pages, and pulling them out closes the page numbering up behind them.
Note in `00 CONTENTS.txt` which exhibit numbers went where, or the index will look like it is
pointing at gaps.

**Everything else** — petition letter plus the remaining exhibits — splits under the shared
size cap. There is no five-file target here: EB-1A packages vary more, so let the split land
where it lands within the 15-file ceiling.

The EB-1A checklist is `EB1A Checklist.docx` (`19Wf_MQp1SHt4ToCycTgvYy1JJ1fKuKVG`); its
sample folder is `0 Sample （EB1A）` (`1w3IBNQgOiFMXVJFAwKZ4SfwHkOWg5_t5`), whose layout —
`1. Information Collection`, `2. Cover/PL/Index`, `3. Forms`, `4. Signature Guidance`,
`5. LOI and Future Plan`, `6. Checklist` — is the map for where each bundle comes from.
