# 凌图小红书笔记

给凌图自己的小红书账号写笔记。读者大多是在美国的华人：签证快到期的、刚出车祸的、想给父母做生前信托的。他们点进来是想弄明白一件事，所以笔记要像一位懂行、说话直接的律师在讲清楚这件事，不要像带货博主。

原版 skill 那套"咱就是说""刷到这篇你在被大数据拯救""300 人验证"已经删掉。律所发这种话，轻则显得不专业，重则违反加州律师广告规则（Rule 7.1：不得有误导性陈述，不得让人对结果产生不合理的期待）。

## 第一步：弄清楚写什么

被调用后先确认三件事。用户一句话里已经说了的就不再问：

1. **主题**：比如"H-1B 抽签新规""车祸后先做什么""生前信托和遗嘱的区别"，或者给一篇现成的文章、案例、新闻让你改写。
2. **类型**：从下面五类里选一个。用户没说就自己判断，在输出开头写一句"按 XX 类写的"。
3. **素材**：有没有官方来源、真实案例。没有就只写能查证的内容，查不到的地方留 `[待确认：……]`，不要编。

时效性的话题（政策、排期、费用、截止日）先用 WebSearch 查最新的官方信息，USCIS、State Department、加州 DMV 之类，再动笔。要看小红书上同类笔记怎么写、大家在评论区问什么，用 agent-reach skill 搜小红书。

## 五类笔记

| 类型 | 适合的主题 | 账号 |
|---|---|---|
| **政策解读** | 新规、排期、费用调整、移民局通知 | 移民 |
| **避坑 / 流程科普** | "H-1B 换雇主要注意什么""车祸后 72 小时""信托要不要每年更新" | 按业务 |
| **成功案例** | 已经发上官网的匿名案例 | 按业务 |
| **问答** | 一个读者常问的问题，一问一答讲透 | 按业务 |
| **律所日常** | 活动、讲座、团队，偶尔发 | 按业务 |

账号：**移民业务用 @凌图蔡神奇移民咨询；车祸、人伤、诉讼、信托遗嘱用 @Lingtu咨询。** 账号名一个字都不改。

成功案例只用已经发布在 lingtulaw.com 上的版本，或者 mkt 流程里 Approved 已勾选的案例。没有经过审核的案子不写成笔记。

## 标题

- **20 个字以内**（小红书标题上限 20 字，超了会被截）。
- 直接说读者能得到什么，或者点出他担心的那件事。数字只用真的数字。
- emoji 最多 1 个，可以不用。
- 给 3 个备选，角度要不同：一个说结论，一个说问题，一个说具体场景。

好的写法：
- H-1B 换工作，这 3 份材料先备好
- 车祸后别急着跟保险公司录音
- 父母在国内，能在美国做信托吗？
- 婚绿面谈被问懵了？常见 12 问

不要这样写：
- ~~💡🔥H-1B 天花板｜逆袭指南｜附工具包~~（堆 emoji 和网络梗）
- ~~100% 获批的 NIW 秘籍~~（结果承诺，违规）
- ~~洛杉矶最好的移民律师告诉你~~（绝对化用语，违规）

## 正文

**字数**：300 到 600 字，小红书正文上限 1000 字。读者在手机上看，宁短勿长。

**结构**（按内容灵活调整，不要每篇都一个样）：

1. **开头一两句**：点出读者遇到的具体处境，或者直接给结论。不要"你是不是也……""经历过 XX 的才懂"这类套话。
2. **主体**：分几小段讲清楚。步骤类用 1. 2. 3.，要点类用短段落。每段说一件事。
3. **结尾**：一句实在的提醒，或者请读者在评论区说说自己的情况。

**口吻**：
- 像律师坐在对面跟你说话，平实、具体、不端着。
- 法律术语第一次出现时用一句话解释，比如"RFE（补件通知，移民局要你补材料）"。
- 签证类别、表格编号写对：H-1B、I-485、I-130、EB-1A、NIW、O-1。
- emoji 全文 0 到 3 个，只放在段首当分隔，不在句中堆。
- 不用"咱就是说""一整个拿捏""绝绝子""宝子们""姐妹们冲"这类网络梗，不用"炸裂""封神""天花板"。
- 信托类写"生前信托"，不写"活人信托"。

**案例类额外要求**：
- 只写官网版本里有的事实，不加细节、不改数字。
- 去掉所有能认出客户的信息：全名、案号、A-number、receipt number、具体日期、雇主名、学校名、小地方的地名。
- 结尾固定加一句："每个案子情况不同，过往结果不代表你的案子会有同样结果。"

**政策类额外要求**：
- 写清楚来源和生效日期，比如"USCIS 2026 年 X 月 X 日公告"。
- 结尾加一句："以上是一般信息，不构成法律意见，具体情况请咨询律师。"

## 话题标签

3 到 6 个，放在正文最后。一两个宽泛的业务标签，加上两三个具体的，比如：

- 移民：#美国移民 #H1B #绿卡 #NIW #EB1A #婚姻绿卡 #美国签证
- 人伤：#车祸 #车祸理赔 #美国车祸 #人身伤害 #洛杉矶生活
- 诉讼：#美国打官司 #合同纠纷 #劳资纠纷 #商业纠纷
- 信托遗嘱：#生前信托 #遗产规划 #美国遗嘱 #信托

不用 #信息差 #小白必看 #干货分享 这类和业务无关的流量标签。

## 评论区引导（CTA）

给两条，一条邀请互动，一条引导关注或看主页。例子：

- "你的情况和哪一条最像？评论区说说，我们挑几个常见的再写一篇。"
- "主页有更多 H-1B 的笔记，换工作前可以翻一翻。"

不要写：
- ~~评论区扣【秘籍】自动发你~~（诱导互动，平台会限流）
- ~~加微信 / VX / 电话 415-xxx~~（站外引流，笔记会被限流甚至封号）
- ~~免费帮你评估成功率~~（结果暗示）

想要读者联系律所，就写"可以私信，或者看主页的联系方式"，不要把电话、微信、网址写进正文或图片里。

## 合规检查（每篇必跑）

写完后把标题和正文一起跑检查脚本：

```bash
node <本 skill 所在目录>/scripts/check_violation.mjs "标题 + 正文全文"
```

红色项必须改，黄色项看上下文判断，判断不了就改掉。脚本只是关键词扫描，跑完还要自己再看一遍下面的红线。

**红线**：
1. **不承诺、不暗示结果**：不写"保证""包过""稳过""100% 获批""必胜""零拒签"，也不写获批率、胜诉率。
2. **不自称专家**：不写"移民专家""XX 领域专家""专精"。加州只有经过 State Bar 认证的律师才能自称 specialist。
3. **不用绝对化用语**：不写"最好""最专业""第一""唯一""顶级"。
4. **不泄露客户信息**：见上面"案例类额外要求"。
5. **不站外引流**：不写电话、微信、二维码、网址。
6. **"不赢不收费"要讲清楚**：人伤笔记提到风险代理，要同时说明律师费以外的诉讼成本由谁承担。拿不准就不提。
7. **不编造**：数字、日期、政策内容、案例细节都要有来源，查不到就留 `[待确认]`。

## 辅助脚本

- `scripts/check_violation.mjs "<文本>"`：合规检查，凌图版词库（结果承诺、资质、绝对化、引流、隐私、平台敏感词）。
- `scripts/hot_words.mjs "<主题>"`：按业务给出候选关键词组合，用来想标题和标签。**它不联网，没有热度数据**，要真实热度就用 agent-reach 搜小红书。
- `scripts/generate_post.mjs "<主题>"`：输出一份空白笔记骨架，提醒结构。正文还是要你按上面的规则写。
- `scripts/xiaohongshu.mjs check|hot|post "<参数>"`：上面三个的统一入口。
