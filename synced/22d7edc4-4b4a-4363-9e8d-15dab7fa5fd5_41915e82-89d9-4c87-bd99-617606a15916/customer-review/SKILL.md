# 好评返现客户群消息（同事一键用）

客户案子有了好结果，同事想请客户做好评返现。这个 skill 生成一整套能直接粘贴进客户群的消息：先是恭喜和返现邀请，再是各平台的参考文案。文案是给客户**参考**的，每个平台互不雷同，客户按自己的经历改几个字就能发。

## 第一步：先问，不要先写

被调用后，**第一句话必须是问业务**，问完等回答，不要提前生成任何内容。用下面这段话（可以略改措辞，但要短）：

> 这个客户是做什么业务的？直接回我就行，比如：
> - 移民：H1B / 婚绿 / O-1 / EB-1A / NIW / I-539 / NOID / RFE / F-1 / 其他
> - 人伤：车祸 / 狗咬 / 工伤 / 摔倒 / 其他
> - 诉讼：合同 / 商业 / 劳资 / 其他
>
> 还有的话可以顺便告诉我（没有就不用说）：结果是什么（获批 / 结案 / 和解）、客户大概什么情况（比如之前被拒过、很着急）、想突出什么（回复快、解释清楚、某位同事很细心）、要中文还是英文。

只问这一轮。回答里已经有业务类型的，不再重复问，直接往下做。如果调用时同事已经把业务写在同一句话里（例如"/customer-review 一个 H1B 客户批了"），可以跳过提问，直接生成。

## 第二步：生成

1. 先跑角度抽签，保证各条的开头、重点、长度都不同（小红书、Google、Yelp、朋友圈，共 4 条）：
   ```bash
   python3 <本 skill 所在目录>/pick_angles.py 4
   ```
   （本 skill 所在目录就是调用时显示的 Base directory。如果运行不了脚本，就自己随机挑：开头角度、重点、长度、结尾各从下面的备选里挑一个，四条互不相同。备选见脚本里的四个列表。）
   每条文案取一行，按抽到的"开头 / 重点 / 长度 / 结尾"写。抽到的长度只是倾向，平台自己的字数范围优先（比如 Yelp 抽到"稍长"也要压短）。更长的分给小红书，较短的分给 Google、Yelp、朋友圈。
   如果抽到的"重点"同事没给任何事实支撑（比如抽到"跟进很细"，但同事没提），只用最笼统的说法（"一直有人跟进"），不要编具体动作。
2. 按下面的消息模板和平台规则写。
3. 过一遍自检清单再输出。

## 输出：两条消息，同事依次粘贴到客户群

### 消息 1：恭喜 + 返现邀请（模板，只替换 `{结果}`）

`{业务}` 写客户的具体业务（H1B、婚绿、NIW、车祸理赔等），不确定就写同事告知的那个词。

`{结果}` 按同事告知的写：获批 → "顺利获批"；结案 → "案子顺利结案"；和解 → "顺利达成和解"。没说就写"顺利"。

```
🎉 恭喜您{结果}！

一路走来，感谢您的信任与配合，也感谢您选择了我们。

如果这段经历对您来说有一点点意义，也欢迎您帮我们留下一个小小的足迹：
无论是一句评价，还是一次转发，都是对我们最大的肯定 💬💙

我们也准备了一个小小的返现活动，作为感谢您的支持和分享。具体步骤可以看群里的指导图～🌟

您每完成一个指定平台（小红书、Google、Yelp、朋友圈），即可获得 $50，全部完成可获得 $200～✨

温馨提示：在 Google 和 Yelp 上留评价时，麻烦写明您办理的具体业务（比如 {业务}），这样我们核对起来更方便，别的客户看着也更清楚～

如果您愿意参与这个活动～完成后将截图和 Zelle 账号发在群内即可，我们将安排金额返现。

下面是我们为您准备的参考文案，您可以按自己的真实经历改几个字再发 👇
```

**消息 1 里的 {业务} 提示是固定要有的**：Google 和 Yelp 评价里必须写明具体业务，这是同事要求的。

这是同事原有话术的合并版：保留原来的语气和结构，金额已改成每项 $50、全部完成 $200，平台加上了 Yelp。不要擅自改动其余措辞。

### 消息 2：四个平台的参考文案（合成一条）

四个平台放在同一条消息里，每个平台一条文案，平台之间空一行，客户自己挑要发的平台：

```
【小红书参考文案】
……正文……
@对应账号
话题：#…… #……

【google map参考文案】
……

【yelp参考文案】
……英文正文……

【朋友圈参考文案】
……

非常感谢[拥抱]
```

四个标题就用上面这四行原样，带【】，不加括号说明，同事习惯这样的写法。朋友圈要配的海报，同事会按"给同事的说明"另发，不用在这条消息里写。

每个平台的写法见下面"各平台规则"。整套输出就是这两条消息，不要再拆成更多条。

### 两条消息之后：给同事的说明（不要发给客户）

紧跟在两条消息后面，用"—"隔开，写这几项：

- **指导图**：同时把好评返现指导图发到群里。移民业务用 [移民好评返现指导图片（含Yelp）](https://drive.google.com/file/d/1r0yJzme1RaMrYt6I1VAaKkLoz2pvWrYz/view)，人伤、诉讼用 [诉讼人伤好评返现指导图片（含Yelp）](https://drive.google.com/file/d/1w3j9OrOmdhk6punHociLfOk3kAmu88RL/view)。
- **朋友圈海报**：朋友圈要配的两张图，见下面"配图"，同事一并发到群里。
- **小红书配图**：见下面"配图"，按业务附对应链接。
- Yelp 固定是英文。Google 默认中文，客户要英文版可以说。
- 想换一批回"再来一版"，只要某一条回平台名。

不要在这之外写长篇说明。"再来一版"要重新跑抽签脚本，并且与上一版的开头和句式都不同。

## 各平台规则

**小红书**（中文）
- 一定要点出项目类型（H1B、婚绿、车祸等），这是返现审核的硬要求。
- 像发笔记：两三小段，1 到 2 个 emoji，不要满屏。
- 带 2 到 4 个话题标签，按业务换，如 #美国移民 #H1B #律师推荐 #车祸理赔。
- 正文最后、话题标签前，单独一行 @ 对应的小红书账号：**移民业务用 @凌图蔡神奇移民咨询；车祸、人伤、诉讼用 @Lingtu咨询**。其他业务没说清楚时用 @Lingtu咨询。账号名一个字都不要改。

**Google Review**（客户习惯英文就写英文，不确定就给中文，并在这条消息后问同事一句要不要英文版）
- 五星，对象是 Lingtu Law APC。
- 40 到 120 字，最多一个 emoji。
- **必须点明具体业务**（H1B、婚绿、NIW、车祸等），写在正文里，自然带出，不要硬塞成标签。
- 说一件具体的事，比泛泛夸"专业"更像真评论。
- 英文要口语自然，不要写成广告词。

**Yelp**（**一律写英文**，不管 Google 用什么语言，也不用问同事）
- 英文要口语自然，像普通客户随手写的，不要写成广告词，不要翻译腔。
- 比 Google 更短，30 到 60 个词，一两个具体细节。
- **必须点明具体业务**（如 H1B premium processing、marriage green card、car accident case），写在正文里。
- 如果同事给的是别的语言的细节，英文里照样只用事实，不加戏。
- 不写网站、电话、优惠，不写返现，不出现"推荐大家都来"这类拉票口气。
- 措辞要和 Google 那条明显拉开，不共用句子。

**朋友圈**（中文）
- 像熟人之间说话，40 到 100 字，一两个 emoji。
- 可以带一句"有需要的朋友可以问我"。

## 按业务取材（取材方向，不是模板）

- **移民**（H1B / 婚绿 / O-1 / EB-1A / NIW / I-539 / NOID / RFE）：身份悬着时的焦虑、政策和材料复杂、时间点紧、有人把流程讲明白、批下来之后的踏实。
- **人伤**（车祸 / 狗咬 / 工伤 / 摔倒）：刚出事时的慌乱、不知道先做什么、有人解释保险和就医、不用一个人面对保险公司。
- **诉讼**（合同 / 商业 / 劳资）：纠纷的压力、法律术语听不懂、有人把下一步分析清楚。
- **其他小案子**：效率高、费用透明、省心。

客户情况里有"之前被拒""很急""家人在国内"这类线索，就用上，那是文案像真人的关键。

## 红线

1. **只写真实发生的事。** 同事没给的细节不编，不写具体天数、金额、"一次就过"。
2. **不承诺、不暗示结果。** 不写"保证""一定""最好的律所"。结果只能写同事告知的那一句，比如"批下来了"，不扩写。同事给了具体时间（如"两个月拿到绿卡"）可以用，但必须写成这位客户自己的经历（"我这次"），不要写成通则，也不要让读者以为人人如此。
3. **不写客户全名、案号、A-number、具体日期。** 人名只在同事明确要点名时用，且只用名字。
4. **不替客户伪造体验。** 这是参考稿，消息 1 里已经写了"按自己的真实经历改几个字再发"，不要删。
