# 移民内容敏感词替换

小红书、抖音等平台会限流或下架带敏感词的移民内容，所以凡是会出现在屏幕上或发出去的文字（字幕、花字、封面、标题、正文、tag），都要按下面的名单处理。人眼扫容易漏，**一定用脚本逐词扫一遍**，不要靠目测。

## 先分清是哪种文字

替换方式取决于文字出现在哪里，所以先判断 mode：

| mode | 用在 | 特点 |
|---|---|---|
| `subtitle` | 字幕、花字（剪辑软件里） | 国旗 emoji 会显示成方框 → 美国写 USA，中国写 China；💰 可以用 |
| `copy` | 小红书标题、正文、tag、朋友圈 | 美国可以用 🇺🇸 |
| `cover` | 封面 | **不用 z / G / J / gwy 这类字母替代**，换成真正的英文或者改写；💰 可以保留 |

## 名单

### 一、固定替换（必须执行）
| 原词 | 字幕/文案 | 封面 |
|---|---|---|
| 美国 | 🇺🇸（字幕里写 USA） | USA |
| 最（最近、最终） | z（z近、z终） | 改写 |
| 政（政策、政府、政治） | z（z策、z府、z治） | 政策→policy，其他改写 |
| 国务院 | gwy | State Dept |
| 规（规定、法规、新规） | G（G定、法G、新G） | 新规→new rule，其他改写 |
| 钱 | 💰 | 💰 |
| 局（移民局） | J（移民J） | 移民局→USCIS，其他改写 |

### 二、延伸替换
- 国会议员 → congressman　国会 → Congress
- 中国 → China　执法 → enforcement
- 费用 → f用　律师费 → legal fee　免费 → free
- 价格 / 多少钱 → 💰　工资 / 收入 → salary / income
- 投资 → tz　中介 → zj（封面上改写）
- 微信 / 加微信 → V / 滴滴　私信 / 电话 / 联系方式 → 主页 / DM
- 链接 / 网址 → 主页
- 非法打工 → unauthorized work　非法 / 黑户 / 偷渡 → undocumented（**尽量整句不提**）
- 遣返 / 驱逐 → deport　庇护 / 难民 → asylum / refugee
- 出国 / 润 → chu国（"利润""滋润"里的润不用改）

### 三、直接不出现（不替换，换个说法或删掉）
- 保证、包过、100%、绝对、第一、唯一、顶级、最好
- 成功率、通过率这类百分比承诺
- 党、国家领导人、敏感时政，对任何国家的负面评价
- 客户真实姓名、案件号、证件号
- "绕过法律""钻空子"之类的说法

律所对外宣传不能做结果承诺，也不能泄露客户信息，这一类不是换个字就能过的，要整句改写。

### 四、不用替换
移民、签证、绿卡、总统、领事馆、大使馆；个案结果和时效描述（"不到1个月拿到""顺利过签"）。这些照常写，不要过度替换，否则观众看不懂。

## 流程

1. 把要检查的文字存成文本文件（字幕可以直接用 .srt），或者用 stdin 传入。
2. 跑脚本，按场景选 mode：
   ```bash
   python scripts/scan.py --mode subtitle 字幕.srt
   python scripts/scan.py --mode copy --fix 文案.txt
   python scripts/scan.py --mode cover --fix -o 封面_改.txt 封面.txt
   ```
   同一条视频的字幕、封面、文案要分别用对应的 mode 跑。
3. 看报告，三种标记：
   - **AUTO**：固定替换，`--fix` 已经改好。
   - **REVIEW**：需要人看一眼——封面上没有现成英文要改写、"润"要看语境、"非法/黑户/偷渡"替换后最好整句删、单字"局"可能误伤（结局、局面）。
   - **BANNED**：承诺用语、极限词、成功率、时政、案件号/证件号等，脚本不会自动改，必须改写或删掉。
4. 处理完 REVIEW 和 BANNED 后**再跑一遍**，直到没有 BANNED、REVIEW 都确认过（脚本全干净时退出码为 0）。
5. 交付时给出改后的文字，并简单列出改了哪些词、哪些句子做了改写。

## 注意

- 脚本是按名单机械匹配，名单之外的敏感内容（比如对某国的负面评价、暗示走后门的说法）要靠阅读判断，扫完再通读一遍。
- 替换后中英文挨在一起时脚本会自动加空格（"USA USCIS"）；读起来别扭的地方顺手调整语序。
- 姓名脚本识别不了：看到客户真名一律删掉或换成"X先生/X女士"。
- 名单要更新时，同时改本文件和 `scripts/scan.py` 里的 `REPLACE` / `BANNED` 表，两边保持一致。
